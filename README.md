# 🔐 PasswordVault — Gestor de contraseñas de escritorio

> **by PALMI-D3V** · Producto digital en desarrollo continuo.

Gestor de contraseñas local-first para escritorio. La interfaz React se comunica con una capa nativa Tauri/Rust que gestiona la bóveda cifrada y el ciclo de vida de la sesión.

## ✨ Funcionalidades

- Crear, abrir, guardar, importar y exportar bóvedas KDBX4 compatibles con KeePass
- Gestión y búsqueda de credenciales
- Generador de contraseñas y señal de fortaleza
- Bloqueo por inactividad
- Diálogos nativos de archivos
- Integración opcional con el llavero del sistema

## 🛠️ Tecnología

React · TypeScript · Vite · Tauri 2 · Rust · KDBX4
